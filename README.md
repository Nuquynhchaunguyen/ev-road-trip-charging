# EV Road Trip Charging Recommendation

Streamlit app for recommending fast-charging stops on a California road trip.

## Run locally

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

For Streamlit Community Cloud, deploy `app.py` from this repository. Keep the GitHub repository **private** if you do not want to publish the source code. App visibility is a separate setting in Streamlit Community Cloud.
